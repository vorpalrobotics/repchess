    Reset to Factory

    ⚠ Reset to Factory

    This permanently and irreversibly deletes everything this app has stored in this browser:

    • Every opening system, move, note, and mnemonic (including images)
    • Every downloaded game
    • The VR memory-palace layout and room progress
    • All saved settings (engine, analysis queue, quiz, auto-import, remembered usernames, etc.)

    There is no undo. Once this runs, none of it can be recovered.
