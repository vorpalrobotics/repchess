Building a Castle: Example

A "castle" is a building in the VR memory palace that maps one branch of your repertoire -- one room per position, one door per prepared reply. Here's the short path from a line in the tree to a walkable building.

1. Mark a castle root

In the move tree, open a position's Attributes and check "starts new castle," then give it a name (e.g. "Dragon Keep"). Leave the street number on Auto unless you want to place it at a specific spot on the street.

2. Generate the castle

Use "Generate Castle" (the dungeon icon) on that root. It previews a room model built from every prepared standard response reachable from that position -- you can inspect the generated rooms in the Castle Preview before committing to anything.

3. Walk in

From the preview, "Walk in VR" drops you at the castle's entry room on the street. Each door corresponds to a prepared reply; walking through one takes you to the position it leads to.

At this point the rooms are built but bare -- see "Decorating Your Castle" for turning them into an actual memory palace.
