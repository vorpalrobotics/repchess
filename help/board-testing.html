Board Play Testing

Menu → Test → Chessboard opens the Opening Quiz -- the way to check whether your preparation actually holds up on a real board, separate from the VR memory-palace walkthrough.

How it works

The quiz plays the opponent's side and expects you to find your own prepared standard response at each step. A wrong or missing move counts as a miss; the session keeps a running hit/miss score as you go.

Setting up a session

Before starting, choose the number of questions, the coverage scope (a whole opening system, a single castle, or everything), a maximum depth, and whether to restrict questions to rooms you've marked memorized.

After a session

The summary shows your score; you can test again with the same set of questions to see if you've improved, or draw a fresh set from the same scope.
