Importing Your Games

Your own games are what populate the move tree with real, played moves and their frequencies -- REPchess uses them to show which replies are actually worth preparing for.

From Lichess or Chess.com

Menu → Import → Games. Enter a username and choose a source: Lichess (by game count) or Chess.com (by number of recent monthly archives). The first import establishes your identity for this browser -- later imports, even from the other platform, add to the same repertoire rather than starting a new one.

Both sources capture full game details -- date, both players, ratings, result, and a link back to the original game -- not just the moves, so you can dig back into any of them later. See Exploring Your Games for what that unlocks.

Keeping it up to date automatically

The import dialog carries a checkbox: "Automatically import new games from these each day." With it on, and a username remembered for either platform, the first time you open REPchess on a given day it checks both sources in the background and merges in anything new. It sizes each request from how long it's been since the last successful check, so a daily user pulls a small batch and someone returning after a month pulls a bigger one.

It's deliberately unobtrusive: it never opens a dialog or interrupts what you're doing. If it finds new games, a toast reports how many and from which platform -- one per source, since the two finish at different times -- and a line in the status bar keeps the summary after the toast fades. A check that finds nothing says nothing. A check that fails (network down, platform unreachable) is silent too, and simply retries on your next refresh rather than waiting out the day.

Pasting variations

Menu → Import → Variations lets you paste move lists directly (useful for lines from a book, a database, or a friend) without needing a full game file.

Local game files

If you open an opening system before any games have been downloaded, you'll be prompted to pick a local file instead -- a Lichess-style NDJSON export (one JSON game record per line), the same format the live Lichess download produces.
