Move Mnemonics: The Default System

A mnemonic in REPchess is a word, a short description, and an image, assigned to a specific piece type landing on a specific destination square (e.g. "knight to f6"). They're the building blocks of the memory-palace technique: a room's decoration is built from the mnemonics of the moves that lead to and from it.

Starting from a ready-made set

Filling in 64 squares × 6 piece types by hand is a lot of up-front work, so on first boot -- if your browser has no mnemonics stored yet -- the app offers to install a default set covering every square and piece. You can accept it to start decorating and drilling right away, or decline and build your own from scratch. The offer only appears once.

Manage Mnemonics

Menu → Mnemonics opens the full 8×8 grid: a "words" view (ABC) that highlights which squares still need a word or image, and a per-piece image view -- one of the piece icons -- for reviewing that piece's pictures at a glance.

Both views can be narrowed to a single opening system or castle with the Repertoire coverage dropdown, so you see only the vocabulary that scope actually asks for. See Customizing Your Images for how each view uses it.
