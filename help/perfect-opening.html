Perfect Opening

A research project that runs in the background: a deep engine search for the objectively best opening line for White. At every White move it keeps the engine's single best move; at every Black move it keeps every reply that scores within a tolerance of the best, and explores each one as a branch of its own. The result is written into an opening system of its own, Perfect White Opening, which you can browse like any other.

Manage

Menu → Perfect Opening → Manage turns the search on or off and tunes it:

  • Pruning tolerance (in centipawns): how close to the best a Black reply must score to be kept as a branch. Wider means many more branches.
  • Total variation cap: the search stops by itself once it has this many lines.
  • Search depth and Max Black replies kept, set per move number, so the early moves can be searched deeply and widely and later ones more cheaply as the tree grows.
  • Hash and Threads: the engine resources it may use.

It only ever uses the engine when nothing else needs it: it waits while the Analysis Queue has work or live analysis is running, so it's safe to give it everything the machine has.

Reset deletes the generated opening system and all progress, and turns the project off. It asks first, since it can't be undone.

Progress

Menu → Perfect Opening → Progress shows whether it's running, how many variations it has generated, how many moves are fully explored, how many positions are waiting, the search speed, and an estimate of how long the current move will take to finish.
