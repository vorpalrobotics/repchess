Marking Rooms as Memorized

Decorating a room is only half the job -- at some point you actually know it. Marking a room "memorized" records that milestone.

Toggling the flag

The brain icon in the VR toolbar toggles the current room memorized or not. It's stored per room and persists across reloads, and shows up as a 🧠 glyph on that room's node in the Opening Graph, so you can see at a glance how much of a castle you've actually learned versus just built.

Using it while testing

Both the mnemonics quiz and board-play testing can be scoped to "only memorized" rooms, so a review session drills what you've already committed to memory instead of mixing in material you're still building out.

It also protects the room's layout

Marking a corridor or two-track room memorized locks its shape in: if a new variation later adds a reply partway through it, that new reply becomes a side-door instead of splitting the room and reshuffling what you've already memorized. A memorized room with a branch inside it instead (not a simple corridor/two-track) shows a ⚠️ warning glyph on the Opening Graph when a new variation lands in it, since its layout can't be frozen the same way -- worth a look before you trust your memory of it.
